# 근거핀 (목업 프로토타입)

보고서·발표 자료의 주장에 원본 설문 데이터를 연결해, 숫자와 해석이 맞는지 제출 전에 확인해주는 서비스의 UI 목업입니다.
실제 AI 분석 로직은 없고, 화면 흐름과 예시 데이터만 보여주는 정적 프로토타입입니다.

## 예시 시나리오
- 대학생 50명 설문, 공모전 참가 경험자 20명
- 참가 경험자 20명에게만 "팀원 모집이 어려웠나요?"를 물었고 12명이 "그렇다"
- 슬라이드에는 "응답자의 60%가 팀원 모집에 어려움을 겪었다"고 적혀 있음 (분모 오류)
- 근거핀이 원본 문항, 실제 응답 대상(20명 중 12명), 수정 문장을 보여줌

## 화면 흐름
1. 홈: 서비스 소개
2. 업로드: 설문 CSV + 발표자료 (목업)
3. 분석 중 로딩
4. 결과: 슬라이드별 정상 / 확인 필요 배지, 요약 카드
5. 문장 상세: 문제 문장, 원본 문항, 발표 수치 vs 실제 응답, 제안 수정 문장
